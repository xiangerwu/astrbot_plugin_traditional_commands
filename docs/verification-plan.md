## 0.2.0 WebUI 驗證

新增 5 項測試：技術字串保留、未知檔案拒絕、完整語系結構與實際插值函式、開關／重複載入／撤回、未知建置或寫入失敗回傳原檔。已核對原 WebUI 檔案雜湊不變，其他 JS、聊天 JSON 與 API 路徑不受轉換。其後已部署、開啟介面繁體化並重載；API 回傳語系資產與本機預期結果完全一致，插件版本為 0.2.0 且啟用，失敗插件清單為空。部署後 16 項回歸測試再次通過。未操作瀏覽器，正式頁面的視覺驗收尚未執行。

## 0.2.1 語言選單

17 項本機測試通過。新增測試執行實際 WebUI i18n 程式片段，驗證繁體選項唯一、旗幟空白、zh-TW 儲存與重新載入，並能切回簡體及其他語言；只有語言偏好儲存鍵被寫入。完整主程式通過 Node.js 語法檢查，i18n 區塊之外的程式碼逐字不變。正式部署結果另以 API 核對，不等於瀏覽器視覺驗收。

0.2.1 已透過 API 更新並重載。主程式含新選單的副本、獨立 zh-TW 語系與保留的原 zh-CN 語系，三者均與本機預期位元組完全一致；介面開關保持開啟，插件啟用且沒有載入失敗項目，原有 170 筆指令／事件元件未變。雜湊依伺服器原始 LF 位元組核對，不對未知檔案放寬檢查。
